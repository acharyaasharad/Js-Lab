# Student Attendance Tracker

Open `index.html` in a browser to view the application.

## Features:
- Add student names and their attendance count
- Displays a table of all attendance records sorted alphabetically
- Automatically calculates and highlights the students with Maximum and Minimum attendance
- Updates the summary dynamically as new records are added

## Usage:
```bash
# on macOS / Linux
open index.html

# or double-click index.html in Finder
```
