# Cart Total Calculator

Open `index.html` in a browser to use the calculator.

## Features:
- Add items with name, cost, and quantity to the cart
- Calculates total cost per item
- Dynamically categorizes items into "Cheap Items" and "Expensive Items"
- Display bill summary in a structured table

## Usage:
```bash
# on macOS / Linux
open index.html

# or double-click index.html in Finder
```
