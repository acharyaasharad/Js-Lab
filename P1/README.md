# Javascript Demo - User Information

Open `index.html` in a browser to view the application.

## Features:
- Accepts user's name and age
- Displays a welcome message dynamically on the page
- Demonstrates different console logging methods (`console.log`, `console.info`, `console.warn`, `console.error`)

## Usage:
```bash
# on macOS / Linux
open index.html

# or double-click index.html in Finder
```
