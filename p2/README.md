# TechShop - Minimal Electronics Store

Open `index.html` in a browser to use the bill calculator.

## Features:
- Minimal electronics shop demo
- Product selection interface
- Calculates subtotal for selected items
- Calculates GST (18%) and final total amount
- Clean and responsive UI

## Usage:
```bash
# on macOS / Linux
open index.html

# or double-click index.html in Finder
```
