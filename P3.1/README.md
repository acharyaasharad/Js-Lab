# SIT Student Login Form

Open `index.html` in a browser to view the login form.

## Features:
- Form validation for Login ID (minimum 3 characters)
- Form validation for Password (requires at least 8 characters, one uppercase, one integer, and one special character)
- Displays inline error messages for invalid inputs

## Usage:
```bash
# on macOS / Linux
open index.html

# or double-click index.html in Finder
```
