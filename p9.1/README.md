# Conference Schedule Manager (Project 9.1)

A dynamic application for managing conference schedules with a theme switcher.

## Features
- Table displaying event times, topics, speakers, rooms, and statuses.
- Add new sessions using a dynamic form.
- Delete existing sessions from the schedule.
- Theme switcher supporting Light, Dark, and Blue themes.
