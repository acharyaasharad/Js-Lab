# Text Tools

Open `index.html` in a browser to use the text utilities.

## Features:
- Input a paragraph and perform various text manipulations
- Find and extract all vowels and list unique vowels
- Search and replace words
- Find the position of a specific word
- Validate and extract email addresses
- Reverse the paragraph text

## Usage:
```bash
# on macOS / Linux
open index.html

# or double-click index.html in Finder
```
